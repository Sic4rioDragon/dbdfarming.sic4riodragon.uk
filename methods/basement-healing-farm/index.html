Basement healing farm

Keep all the hit/heal resets inside basement so every heal is useful progress.

How to do it

  1. Set up the Survivors in basement.
  2. Killer repeatedly injures them there.
  3. Heal the required Health States without leaving basement.
  4. Repeat.

Notes

  • Can be combined with general healing progress such as Medic if those players still need it.
