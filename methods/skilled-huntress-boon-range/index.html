Skilled Huntress boon-range farm

Use a 24m boon radius as an easy in-game distance marker for the hatchet downs.

Skilled HuntressClose Shave

Survivor perks / setup

Any boon with a 24m radius

How to do it

  1. Set up the boon.
  2. Survivors stand around the outside edge of the boon radius.
  3. Huntress stands beside a locker at the correct distance and downs them with hatchets.
  4. Heal everyone and repeat.

Notes

  • Standing beside a locker keeps hatchet refills quick.

Options / variants

Close Shave variant
Before landing the real hatchet, throw close misses around the Survivor. If the game counts them as dodged projectiles, the Survivor can work on Close Shave at the same time.
