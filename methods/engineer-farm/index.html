Engineer damaged-gen rotation

Get one Engineer count from each Generator in the match instead of waiting for random kicks.

Engineer

How to do it

  1. Touch a Generator so it has progress.
  2. Killer damages it.
  3. Achievement hunter repairs that damaged Generator.
  4. Move to the next Generator and repeat once per Generator.
  5. Finish the match normally after the useful Generators have been counted.
