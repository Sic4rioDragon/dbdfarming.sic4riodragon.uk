Survivor

Killer aura farm

Use Still Sight with a cooperating Killer for easy continuous aura reading.

Honour the BloodlineLifting the Fog

Survivor perks / setup

Still SightEyes of Belmont (optional)Fogwise + Deadline (backup option)

How to do it

  1. Have the Killer stand inside Still Sight range.
  2. Stand still until the Killer aura is revealed.
  3. For Honour the Bloodline, simply keep the reveal going long enough.
  4. For Lifting the Fog, move briefly to turn Still Sight off, stand still again, and repeat the reveal cycle.

Options / variants

Lifting the Fog reactivation count
Check that every Still Sight reactivation counts as a new aura reveal. If not, switch to Fogwise + Deadline and farm Great Skill Checks while injured.
