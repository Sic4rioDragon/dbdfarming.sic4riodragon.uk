Survivor

Disturbed Ward achievement stack

A dedicated Disturbed Ward match can potentially stack several annoying escape achievements.

HaemophobiaShock TherapyItem of ObsessionLeft For Dead

Killer perks

Nemesis

How to do it

  1. Load into Disturbed Ward.
  2. Achievement hunter pallet-stuns the Killer so Nemesis makes them the Obsession.
  3. The Killer never hits that Survivor.
  4. Make the special Disturbed Ward Generator the final Generator.
  5. The other three Survivors die and fully reach the dead state.
  6. Achievement hunter finishes the last Generator, opens the Exit Gate and leaves last.

Notes

  • The three other Survivors need to be fully dead before the last Survivor completes the final Generator for Left For Dead.

Options / variants

Four-achievement stack
This setup is intended to combine Haemophobia + Shock Therapy + Item of Obsession + Left For Dead in one match. If any one of them tracks differently on your platform, split it off instead.
