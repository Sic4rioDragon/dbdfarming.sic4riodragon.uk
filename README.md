# dbdfarming.sic4riodragon.uk

Website for https://dbdfarming.sic4riodragon.uk/

DBD bloodpoint farming, organized farming, Asian farming, grades and achievement hunting.

## Folders

- `guides/` - farming guides and FAQ
- `achievements/` - achievement list and individual achievement pages
- `methods/` - detailed farming methods
- `data/` - achievement and method JSON
- `assets/` - CSS and small search/filter scripts

The JSON files are kept as the source for achievement/method information. The public detail pages are also written as normal HTML so search engines can read them directly.
